# Диаграммы Rdk-BasicLib

## RU

### Назначение

Диаграммы структуры библиотеки Rdk-BasicLib и основных последовательностей использования.

### Диаграммы

- [Data-Flow.md](Data-Flow.md) - поток данных в библиотеке
- [Component-Interactions.md](Component-Interactions.md) - взаимодействие компонентов

Все новые диаграммы для компонентов `Rdk-BasicLib` оформляются с использованием `mermaid`:

- Структура классов и иерархия — `classDiagram`.
- Последовательности вызовов и жизненный цикл — `sequenceDiagram`.
- Состояния компонента — `stateDiagram-v2`.
- Алгоритмы и потоки данных — `flowchart TD`.
- Взаимодействие компонентов и подсистем — `graph TB` с `subgraph` для группировки.

## EN

### Purpose

Diagrams of Rdk-BasicLib library structure and main usage sequences.

### Diagrams

- [Data-Flow.md](Data-Flow.md) - data flow in the library
- [Component-Interactions.md](Component-Interactions.md) - component interactions

All new diagrams for `Rdk-BasicLib` components should use `mermaid`:

- Class structure and inheritance — `classDiagram`.
- Call sequences and lifecycle — `sequenceDiagram`.
- Component states — `stateDiagram-v2`.
- Algorithms and data flow — `flowchart TD`.
- Component and subsystem interactions — `graph TB` with `subgraph` grouping.
